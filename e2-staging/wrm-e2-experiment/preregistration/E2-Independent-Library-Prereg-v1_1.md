## 5. Pre-registered classification

**5.1 Null populations — exact, geometry-preserving, non-identity.** Nulls are generated by **predicate relabeling within the intended cover's own incidence structure**: family sizes, total membership multiplicity, and the full pairwise-overlap structure are held **identical by construction**; randomness lies only in which predicate occupies which membership slot. The **domain-structured null** constrains relabeling to within relational-domain blocks (first-class per v0.3 Amendment 1); the **uniform null** relabels without the domain constraint. **The identity cover — the observed, intended arrangement — is not a member of any null population:** sampling is uniform over **unique canonical non-identity relabelings** (canonical-form dedup; the identity form rejected). Counts, exact and frozen: **1,000 unique non-identity domain-structured covers and 1,000 unique non-identity uniform covers** under a recorded seed. **If a null family's valid non-identity population is at or below 1,000, it is enumerated exhaustively.** In both cases the same **observed-plus-null convention** governs: p = (1 + #{null ≥ observed}) / (n + 1), with n the null count actually used; **the manifest records, per null family, whether the population was sampled or exhaustive, and its size when enumerated.** Activation-structure statistics are computed for **all** nulls; synthesis-dependent companions for **exactly 100 covers per null family**, drawn by a frozen seeded rule.

**5.2 Primary criterion — the p-value controls.** The formal gate is the **one-sided empirical permutation test on the structured-differentiation (activation-structure) statistic against the domain-structured null: p ≤ 0.05**, with p as defined in §5.1. **Percentile rank is reported descriptively and is not defined as equivalent to the p-value** — ties can make the two diverge — **and does not control classification; the p-value does.** The report additionally states the margin to the null maximum and the upper-tail shape.

**5.3 Secondary criteria (all required for SURVIVES; per v0.3 Amendment 5 rev. 3):** **coverage** — all four families live under L_R′ (≥ 1 activated condition with a live discrepancy each); **foreign-dial selectivity** — 0.0 at the E1 definition (frozen ε = 0); the qualitative gate criteria pass (necessary, non-discriminating per Amendment 1). These are **frozen gates, not hypothesis tests**: each is reported **relative to its null distribution** for context (E1 reference: null coverage means 1.5 and 2.7; null selectivity means 0.46 and 0.64), and **no percentile-significance requirement attaches to saturated measures** such as 4-of-4 coverage or zero foreign-dial grounding.

**5.4 Companions (reported, never gating):** divergence as manipulation check, stated as a position within the domain-structured null distribution per Amendment 1; the 7-move perturbation set re-run under L_R′; adjacency, derived-triage, and uniform-null comparisons; placebo separation stated distributionally per Amendment 5 rev. 3.

**5.5 Outcomes, named in advance:**

- **SURVIVES** — primary + all secondary hold. Claim, exactly: *a relational assignment developed independently of the reference library predicted distinctive problem-realization structure when confronted with independently authored domain standards — on this scenario, within the frozen vocabulary, at empirical p ≤ 0.05 against geometry-matched domain-coherent chance (percentile reported descriptively).* The CO-DESIGN confound is retired; SCENARIO-AUTHORING and VOCABULARY-SELECTION remain. Next act: E3, the LLM-backed Gate B with an empirical noise band.
- **NON-REPLICATION (CO-DESIGN-CONSISTENT)** — the primary criterion fails. Written finding, exactly: *the E1 differentiation did not replicate when the reference library was independently authored; the present evidence therefore does not establish that the intended assignment possesses library-independent explanatory structure.* This **increases support for the co-design explanation of E1 without establishing causation**. E1's GO is annotated NON-REPLICATED in the evidence record; the library/assignment interface is redesigned before any further credited run.
- **COVERAGE-LOST(w)** — primary passes, a family goes dead: reported per family as **FAMILY-SCENARIO-THIN**, read against both MRC profiles. *Pre-registered expected candidate: Dynamism*, whose E1 liveness hung on the single boundary predicate `has_input`.
- **SELECTIVITY-LOST** — foreign-dial grounding appears under L_R′; reported; not SURVIVES.
- **LIBRARY-INERT** — §4; terminal for E2; any successor is E2b.

**Expected outcome, stated honestly:** genuinely uncertain — the domain-structured null's E1 behavior (60% qualitative pass rate; 0.023 best-cover margin at n = 60) makes both survival and non-replication live, and the geometry-preserving non-identity nulls at n = 1,000 make either answer mean something.
