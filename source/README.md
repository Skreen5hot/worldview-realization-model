# Source directory

The task designates `WRM-Formal-Model-v0_2.md` as the normative architectural source. **That file was not
available** in this repository, its remote, or any sibling repository of the author reachable from the build
session (checked: Integral-Ethics-Engine, Ontology-of-Freedom, IntegratedAgent). It has not been reconstructed or
fabricated here.

`WRM-v0_2-prototype-interpretation.md` records, section by section, the prototype interpretation that was actually
implemented, derived from the task specification's restatement of v0.2. When the real v0.2 document is added to
this directory, each item in that file should be checked against it and any discrepancy recorded in
`docs/assumptions.md`.
